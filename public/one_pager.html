VibeShield AI

Zero-Knowledge Code Security & Credential Protection Engine
Live Web App: hackthonn-two.vercel.app
GitHub Repository: github.com/nikhil24x5183-netizen/securityscanner
1. The Problem Statement We Intend to Address

When building software, developers frequently leave secret API keys, database passwords, and dangerous security bugs inside their source code. Existing security tools are slow, complex to set up, and often give misleading "100% Safe" ratings to risky code. This leaves applications exposed to leaked user data, hacked user accounts, and thousands of dollars in unexpected API billing charges.

2. Our Proposed Solution

VibeShield AI is an instant, browser-based security scanner that checks full project folders for security bugs without uploading private code to external servers. It pinpoints the exact line numbers where problems exist and gives developers clean, copy-paste code to fix them right away.

3. Key Features and Functionality
  • 100% Private In-Browser Scanning: Uses JSZip to unpack and scan code inside local browser memory. Private files never leave your computer.
  • Exact Line Number Finder: Uses character-offset matching to locate the exact file and line number for leaked keys and bugs without line-guessing.
  • Detects 15+ Threat Types: Flags exposed OpenAI, AWS, and Stripe keys, database passwords, SQL Injection, XSS, and dangerous eval() calls.
  • Honest Risk Scoring: Uses strict penalty rules so dangerous code never receives a fake "100% Safe" rating.
  • Instant Copy-Paste Fixes: Generates ready-to-use secure code replacement blocks for every issue found.
4. How We Plan to Leverage the Platform

We leverage the platform's x402 protocol to build an automated, pay-per-scan API endpoint (/api/audit/x402). When AI agents or GitHub Action workflows need deep code security audits, they settle micropayments (e.g., $0.10 USDC per scan) via HTTP 402 headers—unlocking instant, verified security reports without subscriptions or manual API key setups.

5. The Expected Impact and Value of the Solution
  • Saves Money: Prevents developers from leaking API keys that cause thousands of dollars in surprise cloud bills.
  • Protects Data: Helps startups and businesses block SQL injections, XSS attacks, and database leaks before going live.
  • Saves Time: Gives developers instant line-level fixes so they can solve security issues in seconds instead of hours.
6. Innovative and Differentiating Elements
  • Zero-Knowledge Privacy: Unlike traditional tools that require uploading code to cloud servers, VibeShield runs 100% locally.
  • Sub-Second Speed: Scans entire project directories and ZIP archives in less than a second.
  • Frictionless Experience: Requires zero CLI setup or account creation. Simply open the site and drop your folder.
