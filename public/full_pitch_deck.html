2. Problem Statement (HF3-SW-03)

Modern software development heavily relies on external API keys, database credentials, and open-source packages. Traditional secrets scanners rely strictly on naive regex pattern matching, flooding development teams with high false-positive alerts on test placeholders, UUIDs, and base64 blobs.

This noise creates severe alert fatigue, leading developers to ignore security warnings. Furthermore, committed secrets often remain recoverable in version control history. Existing tools fail to validate key structures, guess fake line numbers, and lack actionable remediation—leaving applications exposed to severe data breaches and financial API quota abuse.

3. Proposed Solution

VibeShield AI is a zero-knowledge, in-browser secrets and security auditing engine designed to eliminate false positives and line-guessing errors.

Running 100% locally in browser memory using JSZip, VibeShield scans project directories for exposed credentials (OpenAI, AWS, Stripe, GitHub PATs, DB URIs) and security flaws (SQLi, XSS, RCE). It calculates exact character offsets to pinpoint file paths and line numbers without guessing, providing dual-perspective explanations (Layman + Engineer) and one-click copy-paste safe replacement code.

4. Technical Approach
  • In-Browser Zero-Knowledge Sandbox: Uses HTML5 File API & JSZip to unpack and scan project code locally in memory without uploading private files to external servers.
  • Character-Offset Exact Line Locator: Calculates raw string character offsets (match.index) to map vulnerabilities to exact file paths and line numbers without line-guessing.
  • Semantic Secret Validation & AST Normalization: Normalizes formatting and strips whitespace to distinguish real API secret formats from placeholders and test fixtures.
  • Strict Risk Scoring Engine: Applies a deterministic penalty formula (Start 100; Critical -20, High -12, Medium -7, Low -3) to prevent fake "100% Safe" ratings on dangerous code.
5. Feasibility & Implementation Plan

Feasibility: Built with Next.js 16, React 19, TypeScript, and Vercel. 100% client-side execution results in zero backend cloud server costs and infinite user scalability.

Implementation Plan:

  • Phase 1 (Completed): Multi-file folder & ZIP processing, character-offset line locator, multi-category SAST engine, and interactive results dashboard.
  • Phase 2 (Current): Vercel production deployment and x402 micropayment API integration.
  • Phase 3 (Next): Web Worker multithreading for sub-second scanning of 1GB+ enterprise repositories.
  • Phase 4 (Future): Real-time VS Code editor extension and automated GitHub PR security bot.
6. Impact & Benefits
  • Reduces Alert Fatigue: Eliminates false positives so developers focus on genuine security threats.
  • Saves Money: Prevents secret leaks on GitHub, protecting developers from thousands of dollars in unexpected cloud API bills.
  • Protects Data: Blocks SQL Injection, XSS, and database credential leaks before code reaches production.
  • Speeds Up Fixes: Provides developers with one-click copy-paste clean replacement code for instant remediation.
